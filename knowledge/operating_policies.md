# 운영 정책

기준일: 2026-11-03. 상태: 대표 전달 기준.

사업별 템플릿을 쓴다. 모든 프로젝트에 같은 단계를 적용하지 않는다.

- MARKETING_RETAINER: 월 계약, 채널별 발행 수량, 초안·승인·게시 구분, 수정, 월간 성과, 연장, 수금
- VIDEO_PRODUCTION: 목적, 길이·규격, 원본, 구성, 촬영 또는 원본 분석, 편집, 내부 검수, 고객 시안, 수정 횟수, 최종 승인, 잔금, 납품
- WEB_APP_DEVELOPMENT: 요구사항, 기능 명세, 화면 목록, 일정, 구현, API, 테스트, 고객 검수, 버그, 배포, 유지보수. 구현 완료와 검수 완료를 합치지 않는다.
- EQUIPMENT_RENTAL: 재고, 대여 기간, 반납, 보증금, 배송, 파손, 계약. 제작 프로젝트가 아니다.
- EDUCATION_COURSE: 과정, 회차, 수강생, 수강료, 출석, 과제, 포트폴리오, 수료
- DESIGN_PRINT: 종류, 가로·세로, 해상도, 컬러 모드, 파일 형식, 인쇄 여부, 시안, 수정, 최종 승인

공통 상태 이름은 문의, 견적 작성, 견적 발송, 계약 협의, 계약 확정, 제작 준비, 제작 진행, 내부 검수, 고객 검수, 수정 진행, 납품 대기, 납품 완료, 정산 완료, 종료다. 렌탈과 교육은 이 목록 대신 자기 상태를 쓴다.

우선순위: 납기 초과, 고객과 약속한 납기, 전달할 결과물, 수금 일정, 직원 작업량, 수익성, 고객 중요도, 작업 선후관계. 납기 변경은 대표 또는 권한 있는 담당자 승인 전이다.

의료 영상은 자료 기밀과 접근 권한을 따로 관리한다.

렌탈 예약은 장비 상태와 재고를 확인하기 전에 확정하지 않는다. 계약서에 없는 연체료를 청구하지 않는다.

고객 메시지, 검수되지 않은 파일, 독촉은 대표 승인 없이 보내지 않는다. 입금 기록이 없으면 입금 완료로 표시하지 않는다. 확인되지 않은 계약을 확정 처리하지 않는다.
