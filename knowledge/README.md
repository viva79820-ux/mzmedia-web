# 엠지미디어 기업 지식베이스

기준일: 2026-11-03. 출처는 대표가 같은 날 전달한 초기 기업 지식이다. 운영 DB의 입금·재고·인사 상태가 아니다.

우선순위:

1. 대표가 승인한 최신 정책
2. 실제 계약서와 검증된 운영 DB
3. 최신 직원·고객·프로젝트 기록
4. 이 지식베이스
5. 일반적인 추론

이 문서와 운영 DB가 다르면 운영 DB를 덮어쓰지 않고 충돌을 확인 필요로 남긴다. 확인되지 않은 금액, 수금, 채용, 재고는 사실로 보고하지 않는다.

구분:

- 고정 지식: 기업 개요, 사업 분야, 업무 정책, 운영 절차
- 변경 가능 지식: 직원, 가격, 고객, 계약. 기준일과 확정 상태를 함께 본다.
- 실시간 운영 데이터: 진행률, 업무 상태, 입금, 장비 재고, 직원 작업량. 데이터베이스가 기준이다.
